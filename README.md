# mokkamuhely
-HU
Ez egy egyetemi projektnek készült ahol egy vállalkozást kellett létrehozni, és ahhoz kellett csinálni weblapot notepad-be, word doksit, excel táblázatot, ppt bemutatót és egy google forms-os kérdőívet, én ebből a kihívás miatt bevállaltam a weblapot, és azt is a nehezebbik módon. A feladathoz használtam ChatGPT-t, túlnyomórészt a CSS részéhez, és egy kicsit iránymutatásként a JS részéhez is.
